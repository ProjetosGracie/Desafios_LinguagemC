# 💻 Desafios de Computação em Linguagem C

## 📌 Sobre o projeto

Este repositório reúne **Desafios de Computação desenvolvidos utilizando a linguagem C**.

Os desafios têm como objetivo colocar em prática conceitos fundamentais de programação, desenvolvendo soluções para diferentes problemas por meio de algoritmos e estruturas da linguagem C.

---

## 🎯 Objetivos

Durante o desenvolvimento dos desafios, são trabalhados conceitos como:

* 🧠 Lógica de programação;
* 🔢 Variáveis e tipos de dados;
* 🔄 Estruturas de repetição;
* 🔀 Estruturas condicionais;
* 📋 Vetores e matrizes;
* 🔤 Manipulação de strings;
* ⚙️ Funções;
* 📍 Ponteiros;
* 🏗️ Structs;
* 💾 Manipulação de arquivos;
* 🧩 Estruturas de dados;
* 🔍 Algoritmos de busca e ordenação.

## ⚙️ Como executar

Para executar os programas em C, é necessário ter um compilador como o **GCC** instalado.

### 1. Clone o repositório

```bash
git clone URL_DO_REPOSITORIO
```

### 2. Acesse a pasta

```bash
cd Desafios-C
```

### 3. Compile o programa

```bash
gcc main.c -o programa
```

### 4. Execute

No Windows:

```bash
.\programa.exe
```

No Linux/macOS:

```bash
./programa
```

## 📚 Objetivo acadêmico

Os desafios têm como finalidade desenvolver a capacidade de **resolver problemas utilizando programação**, transformando um problema apresentado em um algoritmo e, posteriormente, em um programa funcional.

A utilização da linguagem C permite compreender conceitos fundamentais que servem como base para o aprendizado de outras linguagens e áreas da Computação.

---

## 🚀 Conclusão

Os **Desafios de Computação em C** proporcionam uma experiência prática de desenvolvimento, permitindo aplicar conceitos de programação na resolução de problemas.

Por meio desses exercícios, é possível desenvolver tanto o **raciocínio lógico** quanto a compreensão dos fundamentos da programação e das estruturas utilizadas pela linguagem C.
