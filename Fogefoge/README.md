# Fogefoge em C

Um jogo desenvolvido em linguagem C durante meus estudos no curso **C: Recursos Avançados**, da Alura.

## Sobre o projeto

O **Fogefoge** é um projeto que estou desenvolvendo para colocar em prática os conceitos de programação em C. A ideia é criar um jogo em que o jogador precisa se movimentar pelo mapa e escapar dos desafios que aparecem durante a partida.

Além de desenvolver o jogo, estou aproveitando o projeto para aprofundar meus conhecimentos em linguagem C e entender melhor como funciona a programação em baixo nível.

## Tecnologias utilizadas

- **Linguagem C**
- **Git e GitHub** para versionamento e acompanhamento do progresso
- **VS Code** para desenvolvimento

## Conceitos praticados

Durante o desenvolvimento, estou estudando e aplicando conceitos como:

- Structs (`struct`) para organizar dados.
- Ponteiros para trabalhar com endereços de memória.
- Alocação dinâmica de memória com `malloc()`.
- Matrizes e manipulação de mapas.
- Funções para organizar e reutilizar o código.
- Leitura e escrita de arquivos.
- Manipulação de strings e caracteres.

## Objetivo

Meu objetivo com esse projeto é fortalecer minha base em programação, entender melhor o funcionamento da memória em C e desenvolver habilidades que serão importantes na minha jornada em Ciência da Computação.

O projeto também faz parte do meu processo de aprendizado prático, no qual busco aprender não apenas a escrever código, mas também a entender o que acontece por trás dele.
